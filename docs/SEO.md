### Що є на кожній сторінці послуги

- **H1** з головним запитом; **H2** — «Що входить у …», «Кому потрібен …», «Як ми працюємо», «Чому обирають «Конкордію»», «Часті запитання», «Залишити заявку»; **H3** — окремі послуги та запитання.
- Унікальні **Title** (до ~60 символів) і **Description** (до ~160).
- Хлібні крихти + розмітка `BreadcrumbList`, розмітка `Service`, загальна `AccountingService` / `LocalBusiness` і `WebSite`.
- Форма заявки, «Корисні статті» з розділу новин, посилання на інші послуги (внутрішня перелінковка).

На головній: рядок «Бухгалтерська компанія «Конкордія» · Харків» входить до H1; секції «З ким ми працюємо», «Основні послуги»,
«Додаткові послуги», меню та футер ведуть на сторінки послуг.

## 2. Індексація

- `https://tyrkovevgen.com.ua/sitemap.xml` — генерується автоматично: головна, послуги, новини та опубліковані статті
  (без чернеток і сторінок з `noindex`).
- `robots.txt` — відкриває сайт, закриває `/admin`, вказує на sitemap.
- Канонічні адреси — на всіх сторінках; фільтри стрічки (`/novyny?katehoriia=…`) вказують на `/novyny`.
- Адмінка: кожну статтю чи сторінку можна закрити від індексації (`noindex`), а в «Аналітика й теги» —
  увесь сайт (лише для тестового домену!).

## 3. Підключення Google Search Console

1. search.google.com/search-console → «Додати ресурс» → **Префікс URL** → `https://tyrkovevgen.com.ua`.
2. Спосіб підтвердження **«Тег HTML»** → скопіюйте мета-тег.
3. Адмінка → «Аналітика й теги» → поле «Google Search Console» → вставте тег → «Зберегти» → у Search Console «Підтвердити».
4. Search Console → «Файли Sitemap» → додайте `sitemap.xml`.

(Альтернатива — підтвердження через DNS-запис у реєстратора домену; тоді поле в адмінці не потрібне.)

## 4. Google Analytics 4 / Google Tag Manager

**Варіант А — лише GA4 (простіше).** analytics.google.com → Адміністрування → Потоки даних → Веб → скопіюйте
ідентифікатор `G-XXXXXXXXXX` → адмінка «Аналітика й теги» → поле «Google Analytics 4».

**Варіант Б — через Google Tag Manager** (якщо маркетолог керує тегами сам). Вставте `GTM-XXXXXXX` у поле «Google Tag Manager»,
а GA4 налаштуйте всередині GTM (тоді поле GA4 лишіть порожнім, щоб не було подвійного рахунку).

Режим згоди (Consent Mode v2): до натискання «Прийняти» в банері Google не ставить cookies і надсилає лише
знеособлені сигнали; після згоди — повноцінна аналітика. Банер з’являється автоматично, щойно задано хоча б один ідентифікатор.

## 5. Meta Pixel

business.facebook.com → Events Manager → Джерела даних → піксель → ідентифікатор (лише цифри) → адмінка
«Аналітика й теги» → поле «Meta Pixel». Піксель завантажується лише після згоди відвідувача на cookies.

## 6. Події конверсій

Сайт надсилає події сам — нічого додатково встановлювати не потрібно.

| Подія GA4 / GTM | Подія Meta | Коли спрацьовує | Параметри |
| --- | --- | --- | --- |
| `generate_lead` | `Lead` | заявку з форми успішно надіслано (головна, сторінки послуг) | `form_location` |
| `click_call` | `Contact` | натиснуто номер телефону | `phone`, `link_location` |
| `click_messenger` | `Contact` | натиснуто Telegram / WhatsApp / Viber / Instagram, зокрема кнопки «Отримати консультацію» | `messenger`, `link_location` |
| `click_email` | `Contact` | натиснуто адресу пошти | `link_location` |
| `share` | — | статтю поширено | `method` |

**GA4:** Адміністрування → Події → позначте `generate_lead`, `click_call`, `click_messenger` як **ключові події**
(з’являться в списку після перших спрацювань). Для Google Ads їх можна імпортувати як конверсії.

**GTM:** події приходять у `dataLayer` під тими самими назвами — тригер «Користувацька подія», назва події = `generate_lead` тощо.

**Meta:** у Events Manager стандартні події `Lead` і `Contact` з’являються автоматично; для реклами оберіть
оптимізацію під `Lead`.

## 7. Заявки

- Форма є на головній (блок «Контакти») і на кожній сторінці послуг: ім’я, телефон, зручний спосіб зв’язку, послуга, повідомлення, згода на обробку даних.
- Заявки зберігаються в адмінці («Заявки») разом зі сторінкою, з якої прийшли, і мітками `utm_*` / `gclid` / `fbclid`.
- Сповіщення в Telegram: змінні `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID` (див. `.env.example`).
- Захист від спаму: приховане поле-пастка, мінімальний час заповнення, не більше 5 заявок на годину з однієї адреси.

## 8. Теги клієнта

Адмінка → «Аналітика й теги» → «Теги клієнта»: довільний код у `<head>` і на початку `<body>` (віджети,
Microsoft Clarity, Hotjar, рекламні мітки). Галочка «лише після згоди на cookies» — для трекерів.
